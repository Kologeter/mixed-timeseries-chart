# mixed-timeseries-chart

График, который принимает четыре time-series и рисует их в одной области разными
способами: **area**, **bar**, **spline**, **line**. Общий тултип по ближайшей дате,
подсветка точек при наведении, утолщение линии при наведении на неё.

Референс: [CleanShot 2026-06-17 at 17.09.14](https://cleanshot.com/share/cBDRxJWM).

- чистый JavaScript (ES-модули), **без зависимостей**, рендер в SVG;
- сборка не нужна: подключается напрямую в браузере или через бандлер;
- есть типы (`src/chart.d.ts`) и unit-тесты на математику (`npm test`).

## Быстрый старт

```bash
git clone <repo-url> mixed-timeseries-chart
cd mixed-timeseries-chart
npm start          # http://localhost:8080/demo/
```

Node.js ≥ 18. `npm install` не нужен — зависимостей нет.
Если порт занят: `PORT=3000 npm start`.

## Инициализация с четырьмя последовательностями данных

```html
<div id="chart" style="width: 315px; height: 166px; background: #fcebeb"></div>

<script type="module">
  import { createChart } from './src/chart.js';

  const chart = createChart('#chart', {
    series: [
      {
        name: 'Cost',
        type: 'area',
        color: '#fcf792',
        yAxis: 'money',           // общая шкала с CPA
        valueDecimals: 2,
        data: [['2026-06-10', 2.04], ['2026-06-11', 25.85], ['2026-06-12', 44.36],
               ['2026-06-13', 55.65], ['2026-06-14', 63.75]],
      },
      {
        name: 'CPA',
        type: 'bar',
        color: '#3670fc',
        yAxis: 'money',
        valueDecimals: 2,
        data: [['2026-06-10', 0.68], ['2026-06-11', 0.86], ['2026-06-12', 1.23],
               ['2026-06-13', 0.79], ['2026-06-14', 0.71]],
      },
      {
        name: 'ROI confirmed',
        type: 'spline',
        color: '#0b8400',
        valueDecimals: 2,
        data: [['2026-06-10', 610.78], ['2026-06-11', 180.5], ['2026-06-12', 161.47],
               ['2026-06-13', 56.33], ['2026-06-14', 357.25]],
      },
      {
        name: 'Conversions',
        type: 'line',
        color: '#b500fe',
        valueDecimals: 0,
        data: [['2026-06-10', 3], ['2026-06-11', 30], ['2026-06-12', 36],
               ['2026-06-13', 70], ['2026-06-14', 90]],
      },
    ],
  });

```

Размер графика берётся из контейнера (`width`/`height` элемента) и
пересчитывается автоматически при его изменении (`ResizeObserver`).
Тот же пример с данными из референса лежит в [`demo/demo.js`](demo/demo.js).

### Формат данных

Каждая серия — `data: DataPoint[]`, где точка задаётся одним из способов:

| Формат | Пример | Комментарий |
| --- | --- | --- |
| `[x, y]` | `['2026-06-10', 2.04]` | x — ISO-строка, timestamp (мс) или `Date` |
| `{ x, y }` | `{ x: 1780963200000, y: 2.04 }` | то же самое, объектом |
| `y` | `2.04` | x = категория из `xAxis.categories` или порядковый номер |

`y: null` — пропуск (разрыв линии, нет столбца, нет строки в тултипе).
Серии могут иметь разные наборы дат: ось X строится по объединению всех x,
а в тултипе показываются только серии, у которых есть точка на этой дате.

Тип оси X: `xAxis.type` — `'datetime'` (по умолчанию, подпись `dd.mm.yyyy` в UTC),
`'category'` (строки как есть) или `'linear'` (числа).

### Оси Y

По умолчанию у **каждой серии своя скрытая ось Y**, поэтому линии с разным
масштабом (ROI ≈ 600 и CPA ≈ 1) видны одинаково хорошо. Чтобы две серии делили
одну шкалу, укажите им одинаковый `yAxis` (в примере выше Cost и CPA — обе в
деньгах). Пределы оси считаются как в Highcharts с `alignTicks`: «красивый» шаг
делений, 5 % запаса сверху, ось начинается с 0, если все значения ≥ 0.

## API

```js
import { createChart, MixedChart } from 'mixed-timeseries-chart';

const chart = createChart(element /* HTMLElement | селектор */, options);

chart.update({ series: newSeries });     // заменить данные/настройки и перерисовать
chart.setSeriesData(2, newPoints);       // заменить данные одной серии
chart.render();                          // перерисовать вручную
chart.pointsAt(index);                   // точки всех серий в слоте index
chart.destroy();                         // снять обработчики, удалить SVG
```

### Опции серии

| Опция | По умолчанию | Описание |
| --- | --- | --- |
| `type` | `'line'` | `'area'` \| `'bar'` \| `'spline'` \| `'line'` |
| `name` | `Series N` | имя в тултипе |
| `color` | из палитры | цвет линии/заливки/маркеров/точки в тултипе |
| `yAxis` | своя ось | id общей оси Y |
| `valueDecimals` | как есть | знаков после запятой в тултипе |
| `valuePrefix` / `valueSuffix` | `''` | обрамление значения в тултипе |
| `lineWidth` | area 1, spline 2, line 1 | толщина линии |
| `fillOpacity` | `0.5` | прозрачность заливки area |
| `smooth` | `true` | сглаживание кромки area |
| `marker` | по типу | `{ enabled, symbol, radius, hoverRadius }`; area → circle, spline → diamond, line → square |
| `visible` | `true` | показывать серию |

### Опции графика

| Опция | По умолчанию | Описание |
| --- | --- | --- |
| `spacing` | `10` | отступ области построения от краёв |
| `backgroundColor` | `'transparent'` | фон SVG |
| `plotBorderWidth` / `plotBorderColor` | `1` / `#cccccc` | рамка области построения |
| `tickPixelInterval` | `72` | желаемый шаг делений скрытой оси Y (влияет на округление пределов) |
| `xAxis` | `{ type: 'datetime', dateFormat: 'dd.mm.yyyy', useUTC: true }` | ось X |
| `tooltip.distance` | `16` | отступ бокса от якоря |
| `tooltip.hideDelay` | `500` | задержка скрытия после ухода курсора, мс |
| `tooltip.snap` | `10` | радиус «захвата» линии курсором |
| `tooltip.headerFormatter` | — | `(label, points, chart) => html` |
| `tooltip.formatter` | — | `(points, label, chart) => html` — полностью своя разметка |
| `halo` | `{ size: 10, opacity: 0.25 }` | подсветка точки при наведении |
| `bar` | `{ width: 16, borderWidth: 1, borderColor: '#fff', borderRadius: 3, hoverBrightness: 0.1 }` | столбцы |
| `hover.lineWidthPlus` | `1` | на сколько утолщается линия при наведении |

## Что повторено из референса

- **Стили**: розовый фон панели, рамка области построения 1px `#ccc`, отступы 10px;
  area с полупрозрачной заливкой и сглаженной кромкой 1px, spline 2px, line 1px с
  квадратными маркерами, тонкие столбцы 16px с белой обводкой и скруглением;
  у каждой серии своя невидимая ось Y с округлением пределов как у Highcharts
  (Cost → 0…75, ROI → 0…750, Conversions → 0…120 на данных из референса).
- **Тултип**: общий для всех серий, заголовок — дата, строки «● Имя: **значение**»,
  белый бокс со скруглением 3px и тенью, появляется у ближайшей по X точки слева
  от неё (справа, если слева нет места; над точкой — если курсор у края),
  плавно переезжает при смене точки, скрывается через 500 мс после ухода курсора.
- **Наведение**: у всех серий в текущем слоте появляется гало (круг r = 10,
  25 % цвета серии) и маркер с белой обводкой (для area/spline маркеры видны
  только при наведении); столбец текущего слота слегка светлеет; линия, которую
  курсор пересёк, утолщается на 1px и остаётся выделенной, пока курсор не
  заденет другую линию или не начнётся новое наведение после ухода с графика.
